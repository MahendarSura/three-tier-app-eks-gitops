# Code of Conduct

## Our Commitment

We are committed to providing a respectful, professional and welcoming environment for everyone who contributes to this project.

All contributors, reviewers and users are expected to communicate respectfully and collaborate in a positive manner.

---

## Expected Behavior

Contributors should:

- Be respectful and professional in discussions
- Provide constructive feedback during reviews
- Respect different technical approaches and opinions
- Help others learn and improve
- Focus on improving the project quality
- Follow project contribution guidelines


---

## Unacceptable Behavior

The following behaviors are not acceptable:

- Harassment or personal attacks
- Offensive or disrespectful comments
- Trolling or intentionally disrupting discussions
- Sharing private information without permission
- Unprofessional communication
- Any behavior that creates an unsafe environment


---

## Project Communication

All communication through:

- GitHub Issues
- Pull Requests
- Code Reviews
- Project Discussions

should remain professional and focused on technical improvement.


---

## Maintainer Responsibility

Project maintainers may:

- Review and moderate discussions
- Request changes in Pull Requests
- Remove inappropriate content
- Restrict participation when necessary


Actions will be taken fairly and based on the severity of the issue.


---

## Reporting Issues

If you notice unacceptable behavior, please report it privately through the repository maintainer contact method.

Reports will be reviewed and handled confidentially.


---

## Contribution Principles

We encourage:

✅ Collaboration  
✅ Knowledge sharing  
✅ Constructive discussions  
✅ Quality improvements  
✅ Respectful teamwork  


Thank you for helping maintain a professional and inclusive DevOps community.
