# 🔐 Security Policy

## Supported Versions

This project currently supports the latest released version.

| Version | Supported |
|---------|-----------|
| Latest Release | ✅ Yes |
| Older Versions | ❌ No |


---

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please do not create a public issue.

Instead, report it privately through:

- GitHub Security Advisories
- Private communication with the repository maintainer


Please include:

- Description of the vulnerability
- Steps to reproduce
- Affected components
- Potential impact
- Suggested mitigation (if available)


---

## Security Practices Implemented

This project follows DevSecOps practices including:

✅ Container image scanning using Trivy  
✅ Infrastructure security using Terraform  
✅ Kubernetes security configurations  
✅ Secure CI/CD pipeline practices  
✅ Dependency and vulnerability checks  


---

## Responsible Disclosure

We appreciate responsible security reporting and will review reported issues as soon as possible.

Security improvements help make this project safer for everyone.
