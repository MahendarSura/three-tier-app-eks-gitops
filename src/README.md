# 📂 Source Code - Three Tier Application

This folder contains the application source code for the three-tier application.

The source code is divided into two main layers:

- Frontend Client
- Backend Server


# 🏗️ Application Architecture

         User
          |
          |
    Frontend Client
          |
          |
    Backend API
          |
          |
    MySQL Database


# 📂 Folder Structure


src/

├── client/
│ └── Frontend application

├── server/
│ └── Backend API application

└── README.md
└── Source code documentation



# 🎨 Client - Frontend

Location:


src/client


The client folder contains the user interface.

Responsibilities:

- Display web pages
- Handle user interaction
- Send requests to backend API
- Display application data


Detailed documentation:


src/client/README.md



# ⚙️ Server - Backend

Location:


src/server


The server folder contains the backend API.

Responsibilities:

- Handle API requests
- Process business logic
- Communicate with database
- Return responses to frontend


Detailed documentation:


src/server/README.md
